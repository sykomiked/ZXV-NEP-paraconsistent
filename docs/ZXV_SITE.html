What is ZXV?

ZXV is a settlement layer on NEAR built on paraconsistent logic — a way of computing that accepts contradictions instead of crashing on them. The one rule: only TRUE settles.

TRUE (0x01)

everyone agrees → settles

BOTH (0x03)

disagreement → recorded, never coerced

NEITHER (0x00)

no evidence → wait

FALSE (0x02)

refused → no

A contradiction never destroys a transaction — it is recorded as information.
