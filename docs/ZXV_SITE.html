What is ZXV?

ZXV is a settlement layer on NEAR built on paraconsistent logic — a way of computing that accepts contradictions instead of crashing on them. A contradiction never destroys a transaction; it is recorded as information. The one rule: only TRUE settles.

TRUE · 0x01

everyone agrees → settles

BOTH · 0x03

disagreement → recorded, never coerced

NEITHER · 0x00

no evidence → wait

FALSE · 0x02

refused → no

The logic, in plain terms

Most systems crash or freeze when two sources disagree. ZXV treats disagreement as information: the contradiction is held (BOTH), never coerced, never a panic. A majority can never force a recorded contradiction to settle — only agreement (TRUE) moves value.

  • TRUE + FALSE = BOTH — recorded, held
  • BOTH is absorbing — a vote can't coerce it
  • only TRUE is settleable — the invariant
  • out-of-range evidence is refused, never coerced to TRUE
